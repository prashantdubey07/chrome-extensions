SHORT DESCRIPTION
Bring in a passage, then explain, summarize, or translate it with on-device AI.

DETAILED STORE DESCRIPTION - COPY THIS
Get help understanding a passage without leaving the page.

Explain This Page brings selected text, article text, or a pasted passage into a reading side panel. On compatible Chrome installations, Chrome’s built-in on-device AI can explain it simply, summarize key points, or translate it.

Features:
- Bring in selected text or the current page’s article after granting access through the toolbar icon.
- Paste and review an English passage of up to 12,000 characters.
- Choose Explain simply, Summarize key points, or Translate when on-device AI is available.
- Choose English, Spanish, Japanese, German, or French output where supported by the installed model.
- Use clearly labeled source excerpts without AI when the browser cannot run the model.
- Copy results, save reading notes with the source used for the result, reopen the original source, and export Markdown.
- Export/import JSON backups, recover unfinished source text and its attribution, and undo the most recent deletion during the current Chrome session.

No account, API key, analytics, or hosted AI endpoint is used by this extension. Chrome may need to download a model. AI availability depends on Chrome’s supported browser, device, storage, language, and administrator-policy requirements. AI can make mistakes; check its output against the source.

Requires desktop Chrome 138 or newer. The current source-language setup expects English text. The non-AI mode shows source sentences; it is not a generated explanation. PDF extraction, cross-origin frames, and shadow DOM are not supported.

SINGLE PURPOSE DESCRIPTION - COPY THIS
Help users understand and retain passages they select or paste by offering reading assistance and saved reading notes.

PERMISSION JUSTIFICATIONS - COPY INTO THE MATCHING FIELDS
storage:
Required to save reading notes, source passages/URLs, and results locally and recover source-text drafts and the most recent deletion during the current Chrome session. Unsaved AI outputs are not sent to a server.

sidePanel:
Required to present the passage, reading-assistance controls, result, and reading-note library alongside the source page.

activeTab:
Required for temporary access to the current page after the user clicks the extension toolbar icon and chooses selected-text or article capture. Pasting text does not require page access.

scripting:
Required to run packaged code that reads only the selected text or requested article/main/body text and page title/URL from the current top-level document. It does not continuously scrape pages or inspect cookies or form fields.

Host permission justification: Not applicable. No permanent host_permissions or optional_host_permissions are declared.

Data handled and why:
User-selected/pasted text or requested page article text; page title and URL; generated results or source excerpts; saved reading-note dates; temporary source drafts/attribution and undo records. Content may include personally identifying information if the user chooses such a passage. AI processes the passage on-device through Chrome’s built-in API.

Clarification:
Personally identifiable information is disclosed conservatively because user-selected/pasted passages can contain names or other identifying details. The extension does not extract a user profile, read cookies, or call a hosted AI endpoint.

Storage/transmission:
Saved records remain in the current Chrome profile; temporary drafts/undo use session storage. No automatic transmission to the developer, advertising, telemetry, or extension-operated cloud sync. User-directed copying, export, field filling, and opening websites can move data to the destination chosen by the user. Review the accompanying policy for exact scope.
