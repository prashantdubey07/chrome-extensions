SHORT DESCRIPTION
Save your tabs and your next step. Come back with context.

DETAILED STORE DESCRIPTION - COPY THIS
Pick up where you left off, with the context you need.

Where was I? saves selected web tabs as a named workspace, along with a note about what to do next. When you return, search your workspaces and reopen the saved pages together in a new window.

Features:
- Choose which web tabs to save from the current window.
- Add a next-step note so you remember why you saved them.
- Edit workspace names and notes, and pin important workspaces.
- Search workspace names, notes, tab titles, and URLs.
- Restore a workspace in a new window while keeping the saved copy.
- Export/import JSON backups and undo the most recent deletion during the current Chrome session.
- Recover unfinished workspace names and notes in the same browser window during the current session.

Your workspaces stay in your Chrome profile. No account, analytics, or extension-operated cloud service is used.

This extension saves URLs and notes, not scroll positions, unsent forms, login sessions, navigation history, or tab groups. Only regular HTTP/HTTPS tabs are supported. Chrome internal pages, local files, and incognito tabs are excluded.

Requires desktop Chrome 116 or newer.

SINGLE PURPOSE DESCRIPTION - COPY THIS
Help users pause and resume browser work by saving selected web tabs together with a next-step note.

PERMISSION JUSTIFICATIONS - COPY INTO THE MATCHING FIELDS
tabs:
Required to read titles and URLs for web tabs in the current window, show the tab-selection list, save the tabs the user chooses, and restore saved workspaces. It is not used to read the complete browsing-history database or page bodies.

storage:
Required to store workspaces, next-step notes, pin status, and dates in chrome.storage.local, and temporary drafts and deletion recovery in chrome.storage.session. The extension does not use chrome.storage.sync.

sidePanel:
Required to show the workspace manager beside the user’s current web page so they can select tabs, write a next-step note, and resume saved work.

Host permission justification: Not applicable. No permanent host_permissions or optional_host_permissions are declared.

Data handled and why:
Selected open-tab URLs and titles; workspace names, next-step notes, creation dates, pin status, and temporary drafts/undo records. Only the tabs the user selects are saved. The extension does not read page bodies or the complete browser-history database.

Clarification:
If your intended use includes storing personally identifying details in workspace notes, also disclose Personally identifiable information. Notes are free text; the extension does not extract a user identity or profile.

Storage/transmission:
Saved records remain in the current Chrome profile; temporary drafts/undo use session storage. No automatic transmission to the developer, advertising, telemetry, or extension-operated cloud sync. User-directed copying, export, field filling, and opening websites can move data to the destination chosen by the user. Review the accompanying policy for exact scope.
