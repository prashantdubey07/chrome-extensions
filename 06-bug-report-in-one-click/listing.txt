DETAILED STORE DESCRIPTION - COPY THIS
Turn a browser problem into a report someone can act on.

Bug Report in One Click captures the current page’s visible viewport and basic browser context, then helps you describe how to reproduce the issue. Review the screenshot, cover private details, and download a report ready to share yourself.

Features:
- Capture the visible page screenshot, URL, title, browser user-agent, viewport/screen size, pixel ratio, and capture time after granting page access through the toolbar icon.
- Drag over private details to cover them with solid rectangles, undo the latest redaction, or reset redactions.
- Add steps to reproduce, expected/actual behavior, severity, and frequency.
- Save and search report text locally.
- Download Markdown or copy a report.
- Download a ZIP containing the current report and redacted PNG together.
- Export/import text-record backups, recover unfinished report text, and undo the most recent deletion during the current Chrome session.

No report is submitted automatically, and no screenshot is uploaded by the extension. Screenshots stay in panel memory and are lost when the panel closes or reloads; download them to keep a copy. Saved reports and backups contain report text, not screenshots.

The extension does not collect console logs, network traffic, cookies, or browsing history. Screenshot capture is limited to the visible viewport, and protected browser pages may block access. Review URLs and screenshots for private details before sharing exported files.

Requires desktop Chrome 116 or newer.

SINGLE PURPOSE DESCRIPTION - COPY THIS

Data handled and why:
On request: current page URL/title, visible-page screenshot pixels, browser user-agent, viewport/screen dimensions, pixel ratio and capture time. Users enter report titles, reproduction steps, expected/actual behavior, severity, frequency and environment notes. Redaction pointer coordinates/rectangles are used transiently in the screenshot editor, not as behavioral analytics. Report text/dates and temporary drafts/undo records stay locally; screenshot pixels stay in panel memory unless explicitly downloaded.

Clarification:
Personally identifiable information is disclosed because screenshots and report text may include names, email addresses, or other identifying details visible on the page. No device fingerprint, account ID, cookies, console logs, or network-monitoring data is collected. Redaction gestures are editor input, not general user-activity tracking.

Storage/transmission:
Saved records remain in the current Chrome profile; temporary drafts/undo use session storage. No automatic transmission to the developer, advertising, telemetry, or extension-operated cloud sync. User-directed copying, export, field filling, and opening websites can move data to the destination chosen by the user. Review the accompanying policy for exact scope.
