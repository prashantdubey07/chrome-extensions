SHORT DESCRIPTION
Save reusable answers, fill a field you choose, and keep your documents in order.

DETAILED STORE DESCRIPTION - COPY THIS
Spend less time typing the same answers into online forms.

Form Companion keeps reusable answers and a document checklist beside your browser. Copy an answer, personalize a template, or fill a specific field that you choose.

Features:
- Save, search, edit, and copy reusable answers.
- Add placeholders such as {{name}} and {{company}} and preview the completed answer.
- Scan a page’s supported field labels after granting access through the toolbar icon.
- Choose both a saved answer and a website field before filling it.
- Keep a checklist of required documents without uploading the documents themselves.
- Export/import JSON backups, recover unfinished text drafts, and undo the most recent deletion during the current Chrome session.

The extension does not submit forms automatically. It excludes password fields and common payment/one-time-code fields from scanning, but this is not a universal sensitive-field detector. Review the selected field and the filled answer before submitting a website form.

Supported fields are visible, enabled text/email/telephone/URL/search inputs and textareas in the top-level page. Cross-origin frames, shadow DOM, custom editors, and some complex forms are not supported.

Answers and checklist records stay in your Chrome profile. Placeholder values stay in the open panel only. No account, AI service, analytics, or application backend is required. Avoid saving passwords or payment details as reusable answers.

Requires desktop Chrome 116 or newer.

SINGLE PURPOSE DESCRIPTION - COPY THIS
Help users prepare and complete online forms using reusable answers, explicitly chosen field filling, and a required-document checklist.

PERMISSION JUSTIFICATIONS - COPY INTO THE MATCHING FIELDS
storage:
Required to save reusable answers and document-checklist items locally, and to recover unfinished form text and the most recent deletion during the current Chrome session. Placeholder values and website field values are not stored as draft records.

sidePanel:
Required to keep reusable answers, template preparation, field selection, and the document checklist visible beside the online form the user is completing.

activeTab:
Required for temporary, user-initiated access to the current website after the user clicks the toolbar icon. Access is used only when the user requests field scanning or chosen-field filling; there is no permanent host access.

scripting:
Required to run packaged code in the current page’s isolated world to enumerate supported field labels/types, track the scanned elements, and set the value of the field the user explicitly chooses. The code does not submit the form or read existing field contents.

Host permission justification: Not applicable. No permanent host_permissions or optional_host_permissions are declared.

Data handled and why:
Reusable answer names/text, template text, document/task labels and completion state, dates, temporary drafts/undo records, and user-entered placeholder values. On request it reads the current page URL, supported field labels/types, and element references to safely fill the chosen field. It does not read existing field values during scanning or upload documents.

Clarification:
Personally identifiable information covers names, email addresses, telephone numbers, and other identifying details users may intentionally enter into reusable answers or placeholder values. No account identifiers are extracted automatically.

Storage/transmission:
Saved records remain in the current Chrome profile; temporary drafts/undo use session storage. No automatic transmission to the developer, advertising, telemetry, or extension-operated cloud sync. User-directed copying, export, field filling, and opening websites can move data to the destination chosen by the user. Review the accompanying policy for exact scope.
